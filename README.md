# Event Expense Tracker
ระบบบันทึกค่าเดินทางไป Event — หน้า Admin (`index.html`), ฟอร์มพนักงาน (`form.html`), backend (`code.gs` บน Google Apps Script) เก็บข้อมูลใน Google Sheets และไฟล์ใน Google Drive

## ไฟล์ในชุดนี้

| ไฟล์ | วางที่ไหน | หมายเหตุ |
| --- | --- | --- |
| `code.gs` | Google Apps Script (แทนของเดิมทั้งไฟล์) | ต้อง deploy ก่อน |
| `index.html` | Vercel (repo เดิม) | หน้า Admin ใหม่ |
| `form.html` | Vercel (repo เดิม) | ฟอร์มพนักงานใหม่ |
| `vercel.json` | Vercel | เหมือนเดิม ไม่ได้แก้ |

⚠️ **ต้องอัปเดตทั้ง 3 ไฟล์ในรอบเดียวกัน** — `code.gs` ตัวใหม่บังคับใช้รหัส Admin หน้า Admin ตัวเก่าจะเรียกข้อมูลไม่ได้

## ขั้นตอน deploy (ประมาณ 15 นาที)

### 0. สำรองข้อมูลก่อน
1. เปิด Google Sheet ของระบบ → ไฟล์ → **ทำสำเนา** (เก็บไว้เผื่อย้อนกลับ)
2. เก็บไฟล์ `index.html`, `form.html`, `code.gs` ตัวเดิมไว้ในเครื่อง

### 1. อัปเดต Apps Script
1. เปิดโปรเจกต์ Apps Script → เปิดไฟล์ `code.gs` → ลบของเดิมทั้งหมด → วางโค้ดใหม่ → กดบันทึก
2. ตั้งรหัส Admin:
   - หาฟังก์ชัน `setAdminPasscode` (อยู่ช่วงต้นไฟล์)
   - แก้ข้อความ `'ตั้งรหัสของคุณที่นี่'` เป็นรหัสที่ต้องการ
   - เลือกฟังก์ชัน `setAdminPasscode` ที่แถบด้านบน → กด **Run** (ครั้งแรกจะถามสิทธิ์ ให้กดอนุญาต)
   - เห็นข้อความ “ตั้งรหัส Admin เรียบร้อย” ใน Execution log แล้ว ลบรหัสออกจากโค้ดได้เลย (รหัสถูกเก็บใน Script Properties แล้ว)
3. Deploy โดย **ใช้ URL เดิม**: Deploy → **Manage deployments** → กดไอคอนดินสอ (Edit) ของ deployment เดิม → Version: **New version** → Deploy
   - อย่ากด “New deployment” เพราะจะได้ URL ใหม่ และต้องไปแก้ `API_URL` ในหน้าเว็บทั้งสองไฟล์

> ไม่ต้องรัน `setupSheets` — คอลัมน์ `close_at` และชีต `SubmissionHistory` ระบบสร้างให้เองเมื่อใช้งานครั้งแรก (ถ้าเผลอรัน `setupSheets` ตัวใหม่ก็ไม่ล้างข้อมูลแล้ว)

### 2. อัปเดต Vercel
1. แทนที่ `index.html` และ `form.html` ใน repo ด้วยไฟล์ใหม่
2. ทั้งสองไฟล์ใช้ `API_URL` เดิมอยู่แล้ว (บรรทัด `const API_URL = '…/exec'`) ถ้า URL ของ Apps Script เปลี่ยน ให้แก้ทั้งสองไฟล์
3. Push / deploy ตามปกติ

### 3. ทดสอบหลัง deploy (5 นาที)
- [ ] เปิดหน้า Admin → ใส่รหัส → เห็นรายการกิจกรรมพร้อม “ส่งแล้ว x/y คน”
- [ ] เปิดกิจกรรม → กด “ดู” ใบเบิกของคนหนึ่ง → เห็นรูปหลักฐานและประวัติการส่ง
- [ ] เปิดลิงก์ฟอร์ม → เลือกชื่อ → กรอก → ส่ง → ได้ไฟล์ PDF และ Word ลงเครื่อง
- [ ] กลับไปหน้า Admin → คนนั้นขึ้น “ส่งแล้ว”

## ย้อนกลับถ้ามีปัญหา
- Apps Script: Deploy → Manage deployments → Edit → เลือก Version เดิม → Deploy
- Vercel: Redeploy commit ก่อนหน้า
- ข้อมูลใน Sheet ไม่ถูกลบหรือย้าย — มีแค่คอลัมน์ `close_at` และชีต `SubmissionHistory` เพิ่มมา ระบบเดิมไม่สนใจสองอย่างนี้

## สิ่งที่เปลี่ยน (สรุป)
- **ความปลอดภัย:** รหัส Admin สำหรับคำสั่งฝั่ง Admin · อ่านไฟล์ได้เฉพาะในโฟลเดอร์ของระบบ · กันข้อความที่ผู้ใช้กรอกไปรันเป็นโค้ด
- **ความถูกต้องของข้อมูล:** LockService กันบันทึกทับกัน · เก็บประวัติทุกครั้งที่ส่งใหม่ และกู้คืนได้ · `setupSheets` ไม่ล้างข้อมูลแล้ว
- **ความเร็ว:** จำ ID โฟลเดอร์แทนการค้นทั้ง Drive · Export หลายกิจกรรมใน request เดียว · ดาวน์โหลด ZIP แบบขนาน
- **ฟีเจอร์ใหม่:** ตั้งเวลาปิดรับและขยายเวลา · บันทึกร่างอัตโนมัติ (ทั้งสองหน้า) · ไฟล์ Word (พนักงานได้อัตโนมัติตอนส่ง / Admin ดาวน์โหลดเป็นรายคนหรือ ZIP) · เพิ่มรายชื่อทีละหลายคน (พิมพ์หรือวางจาก Excel) พร้อมตรวจชื่อซ้ำ
- **หน้าตา:** ออกแบบใหม่ทั้งสองหน้าตาม Design Board · ใช้บนมือถือได้ · ข้อความยาวไม่ทำให้หน้าเพี้ยน

## หมายเหตุ
- ไฟล์ Word ใช้ฟอนต์ **TH Sarabun New** ขนาด 12 — เครื่องที่เปิดต้องมีฟอนต์นี้ ไม่อย่างนั้น Word จะใช้ฟอนต์อื่นแทน
- Chrome อาจถามครั้งแรกว่าอนุญาตให้เว็บดาวน์โหลดหลายไฟล์ไหม (PDF + Word) ให้กดอนุญาต
- บันทึกร่างเก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น ร่างจาก URL ของ Vercel กับ URL ของ Apps Script แยกกัน
